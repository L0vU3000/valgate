# Valgate API Specification

Single source of truth for the Valgate API contract.

## Format

OpenAPI 3.1 YAML specification defining all endpoints, request/response schemas, and error shapes.

## Usage

### Generate TypeScript types (web)
```bash
pnpm api:generate-ts
```

### Generate Swift types (iOS)
```bash
pnpm api:generate-swift
```
